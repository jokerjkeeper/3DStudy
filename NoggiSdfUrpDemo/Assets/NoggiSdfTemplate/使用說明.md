# Noggi SDF 與反殼描邊 · Unity URP

已在 Unity 6000.3.15f1 / URP 17.3.0 驗證。搬到其他專案時，先確認該專案已啟用 URP，再匯入 NoggiSdfTemplate-URP.unitypackage。包內包含 Shader、材質範本、頭部方向綁定和編輯器工具。角色、貼圖及 Unity Toon Shader 可以各自接入。

## 把臉部 SDF 接到自己的 FBX

1. 在 Blender 或 Bforartists 讓**臉部皮膚有獨立材質槽**。眼白、眼睛、睫毛、眉毛和嘴內可保留原材質。匯出 FBX 時確認臉部材質槽和 UV 一起匯出。
2. 在 Unity 複製 Face Template 材質。把原始臉部底色拖入 **Base color (UV0)**，把 SDF 貼圖拖入 **SDF mask**。底色使用一般 sRGB 匯入。SDF 遮罩關閉 sRGB、設為無壓縮，Max Size 至少等於貼圖尺寸。預設單張遮罩可用 Clamp。
3. 如果角色自帶配套 SDF，先沿用其指定的臉部 UV。若要套 Noggi 的通用貼圖，建議在建模軟體複製一套臉部 UV，從正面投影，讓鼻中線對齊貼圖中央、額頭對上方、下巴對下方，再調縮放到陰影圖形吻合。底色可保留原 UV0，將第二套 UV 作為 UV1 輸出並把材質的 **SDF UV channel** 選為 UV1。若用 UV1 給 SDF，Unity FBX 的 Generate Lightmap UVs 要關閉，以保留第二套 UV。只有一套 UV 時選 UV0。
4. 把 FBX 拖進場景，開啟 **Tools → Noggi SDF → Character Setup**。填 **Target Renderer** 和臉部皮膚的 **Material Slot**，拖入新材質後按 **Assign Face Material**。
5. 如果角色會轉頭，建一個空物件作為頭骨的子物件，讓空物件本地 **−Z 朝臉前、+X 朝正面畫面右側**。把它拖進 **Head Basis** 再按一次 Assign。沒綁 Head Basis 時，Shader 用 Renderer 的本地軸向。
6. 確認場景有一盞主 Directional Light，並在 Lighting 的 Environment 中指定為 **Sun Source**。測正面與左右兩側。左右相反就切 **Reverse left/right convention**，黑白顛倒才切 **Invert mask values**。用 **Preview → Mask** 或 **Unmirrored UV** 看遮罩及座標，完成後切回 Shaded。

### 兩個遮罩範例

| 遮罩 | 材質與匯入設定 |
|---|---|
| Noggi 通用 SDF | Mask channel 選 Red、Threshold response 選 Linear azimuth、Front/Back thresholds 用 0/1。Decode sRGB-encoded mask RGB 關閉。 |
| Perlica 原附 SDF4（原始遮罩對照） | 用既有臉部 UV0，Mask channel 選 Packed B to R by G（用綠通道混合藍、紅），開啟 Decode sRGB-encoded mask RGB。貼圖維持 Linear 匯入、Repeat。範例用 Cosine azimuth，Front/Back thresholds 為 -0.015/0.30。 |

Perlica 場景目前用從 SDF4 的主要側邊輪廓整理出的 PerlicaFaceSdfClean.png。這張遮罩維持原 UV0，Red、Quick azimuth、0.035/0.98、Clamp。Quick azimuth 讓側臉陰影較早進入臉部，常規 Noggi 材質仍可選 Linear azimuth。原始 SDF4 仍保留在本地專案，直接以門檻切分時，鼻中線和臉頰的細節可能分裂出零碎陰影。

角色有局部唇部光澤貼圖時，把它放到 Optional lip gloss，使用跟底色相同的 UV0。貼圖 Alpha 限定光澤區域，再調 Lip gloss strength。
 
每張遮罩各自對應一套臉部 UV。自己的角色有配套貼圖時可以直接沿用其 UV，套別套貼圖時要重新對齊鼻、眼與下巴的位置。可使用材質上的 **Tiling／Offset** 做少量校正。此材質以主光方位計算臉部陰影，尚未接髮絲投影或場景遮蔽物的陰影。

## 加反殼描邊

1. 複製 **Outline Template**，設定顏色與 **Width in world units**。人物約 1.6 m 高時，可從 0.001–0.003 開始。
2. 在同一個工具選擇要描邊的 Renderer，拖入 Outline Material，再按 **Create or Update Inverted Hull**。臉部多材質時可勾 **Only This Material Slot**，保留眼睛和睫毛的原狀。髮或衣服可各自有自己的粗細。
3. 工具會新增或更新子物件 **Noggi Inverted Hull**。靜態網格沿用 Mesh，蒙皮網格沿用 Mesh、骨架和骨骼權重，Blend Shape 權重會在 Play Mode 跟隨來源。要開關描邊，切這個子物件的啟用狀態。髮片等透明網格先挑選適合描邊的幾何或材質槽。
4. 身體保留原來的材質，或用 Unity Toon Shader 做分色。若同一組網格用了此處的反殼，就將該材質的內建描邊寬度設為 0，避免畫兩圈。

## 瀏海投影

Perlica 場景可在 Play 中獨立切換 Face SDF 和 Bangs shadow。關閉 SDF 時會使用臉部亮色，瀏海投影仍可疊上。它以主方向燈擷取額頭前方的髮片，再讓臉部材質取樣投影深度。SDF 負責整張臉的分色，瀏海投影會疊在同一張臉上。

套其他角色時，在臉部加入 Bangs Shadow Projection，Caster 指定頭髮 Renderer 與瀏海材質槽，Receiver 指定臉部 Renderer 與皮膚材質槽。頭髮若是一個材質槽，仍可用 Half Width、Minimum Height、Minimum Forward 限定額頭前方的髮片。Depth Shader 選 Hidden/Noggi SDF Toolkit/Bangs Depth；Key 指定主方向燈，也可讓元件使用場景的 Sun Source。Head Basis 與 Local Forward 的組合應朝角色臉前。臉部使用本模板的 Face shader。
